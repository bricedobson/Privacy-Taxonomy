# Privacy Reference Model

A reference data model for organizational privacy operations, grounded in the [W3C Data Privacy Vocabulary (DPV)](https://w3id.org/dpv) and spanning 12 privacy capability subdomains.

## Explore the Model

The best way to explore this work is through the **interactive Reference Data Model Explorer**:

###  [PrivacyReferenceModel.com](https://PrivacyReferenceModel.com)

The explorer supports graph visualization with maturity filtering, layer isolation across core and periphery, regulation profile extensions, and browsable catalogs of subdomains, entities, relationships, and decisions.

## Repository Contents

| File | Description |
|------|-------------|
| `index.html` | Page source for the interactive explorer application |
| `data/model.json` | The reference data model (entities, relationships, decisions, and maturity metadata) |
| `Paper.pdf` | The accompanying paper |

The rest of the files can be ignored, they are the associated files for the LaTeX source of `Paper.pdf`.

## Getting Started

Visit [PrivacyReferenceModel.com](https://PrivacyReferenceModel.com) to browse the model interactively — no setup required.
